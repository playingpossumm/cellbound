# Cellbound

Variant sudoku in the browser: a daily puzzle, roguelite runs, fog-of-war boards, free play and short lessons, in six hand-made looks. Everything runs on your device; progress stays in the browser.

## Run it

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the dev server.
- `npm run build` type-checks and builds to `dist/`.
- `npm test` runs the unit tests.
- `npm run gen:daily` regenerates the precomputed daily puzzles.
- `npm run e2e` runs the browser tests.
